# MS PROJECT 2016

MS PROJECT 2016

Aprende a gestionar profesionalmente un proyecto mediante el uso de Microsoft Project. Emplea la herramienta para desarrollar planes, asignar recursos, dar seguimiento al progreso, administrar el presupuesto y analizar cargas de trabajo.

Docente

Ing. Juan Pablo Suligoy

UTN - Reconquista

En este curso aprenderás a

- Gestionar eficientemente un proyecto mediante una herramienta informática.
- Definir tareas de sumario y repetitivas.
- Usar plantillas y conocer sus ventajas.
- Asignar y nivelar recursos a cada tarea.
- Manejar y gestionar los costos por cada recurso.
- Vincular proyectos y generar reportes sobre los mismos.
- Realizar evaluaciones finales sobre resultados.
