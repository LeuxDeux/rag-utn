# Sistemas de Gestión

SysAcad para estudiantes

Inscripción a cursado y a exámenes, y consulta de tu situación académica.
- Inscripción a cursado: las materias de cada cuatrimestre, según las correlatividades.
- Inscripción a exámenes: la mesa de cada llamado del calendario académico.
- Situación académica: materias aprobadas, regularidades y notas.
- Correlatividades: qué podés cursar o rendir según lo que ya aprobaste.
